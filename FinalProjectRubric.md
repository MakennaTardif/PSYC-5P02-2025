# Final project grading rubric

| Topic                                                                                | Needs Improvement                                                                                                                                                                                                                                       | Satisfactory                                                                                                                                                                                                                                                                        | Excellent                                                                                                                                                                                                                                                                                                                                    |
|:---------------|:---------------|:-----------------|:---------------------|
| Coding style (clarity)                                                               | Many errors in code, code is easily read                                                                                                                                                                                                                | Code is readable, but coding style could be refined and has some errors.                                                                                                                                                                                                            | Student has gone beyond what was expected and required, code demonstrates high levels of mastery and elegance                                                                                                                                                                                                                                                             |
| Coding efficiency                                                                    | Code tackles complicated problem in one big chunk. Code is repetitive and could easily be made more efficient.                                                                                                                                          | Code is works, but could be edited down to leaner code.                                                                                                                                                                                                                             | Complicated problem broken down into sub-problems that are individually much simpler. Code is efficient and minimal.                                                                                                                                                                                                                         |
| Documentation                                                                        | Very little earnest effort to document code. Code difficult to navigate.                                                                                                                                                                                | Satisfactory effort to clearly communicate thinking. Some explanation of how to implement code properly, with minimal friction.                                                                                                                                                     | Student has gone beyond what was expected and required. Code thoroughly documented. Clear instructions for how to impliment and run code with no user friction.                                                                                                                                                                              |
| Complexity, scale or tasks/analysis, and mastery                                     | Student does not display the expected level of mastery of the tools and techniques in this course. Chosen task was too limited in scope.                                                                                                                | Tools and techniques from the course are applied very competently and, perhaps, somewhat creatively. Chosen task was acceptable but fairly conservative in ambition.                                                                                                                | Student has gone beyond what was expected and required, e.g., extraordinary effort, additional tools not addressed by this course, unusually sophisticated application of tools from course.                                                                                                                                                 |
| Completeness                                                                         | Code does not run, and/or not all components included. Code not submitted properly or easy to access.                                                                                                                                                   | Satisfactory                                                                                                                                                                                                                                                                        | Access as easy as possible; code runs!                                                                                                                                                                                                                                                                                                       |
